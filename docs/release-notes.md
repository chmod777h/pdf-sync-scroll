PDF Sync Scroll 1.2.0 prepares the local plugin for public distribution.

- Synchronize two or more selected PDF panes, including popout windows.
- Align by page number and fractional position, overall progress, or manual offsets.
- English interface by default; Simplified Chinese text for Chinese app locales.
- Searchable settings using Obsidian's declarative settings API.
- Reject unsupported spread and scrolling modes; recover from malformed saved settings.
- Close open selectors and release listeners, observers, and queued frames on unload.
- Include MIT license, bilingual documentation, regression tests, and release automation.

Requires Obsidian desktop 1.14.4 or later. macOS 1.14.4 is the verified baseline; Windows/Linux application testing and future-version compatibility are not claimed. Mobile is excluded. See docs/compatibility.md for evidence and limits.
