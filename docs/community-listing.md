# Community listing text

Name: PDF Sync Scroll

Short description: Synchronize scrolling across selected PDF panes and popout windows, with page alignment, reading progress, and manual offsets.

Long description:

Compare an original PDF with a translation or reference document without repeatedly finding your place. PDF Sync Scroll links two or more selected PDF panes, including popout windows in the same vault. Scroll any selected pane to move the others.

Choose page-and-position alignment, overall reading progress, or pause and manually align corresponding content. Different page sizes and zoom levels are supported. Unselected panes remain independent.

Requires desktop Obsidian 1.14.4 or later, with vertical continuous scrolling and no page spreads. The verified application baseline is macOS 1.14.4; see the repository's compatibility report for testing details. The plugin is free, works offline, has English and Chinese UI, and does not modify PDF files or collect telemetry.
